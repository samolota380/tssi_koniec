Model pudełkowy (Box Model)

Margin, border, padding, content, background

Wyjaśnienie

Każdy element to pudełko: content → padding → border → margin. Box-sizing wpływa na sposób liczenia szerokości.

Przykład

.box { width: 300px; padding: 20px; border: 5px solid #333; margin: 10px; }
* { box-sizing: border-box; }

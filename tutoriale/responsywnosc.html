Responsywność

Media queries, picture/source, srcset, meta viewport

Co oznacza responsywność?

Responsywność to zdolność strony do zmiany układu w zależności od szerokości ekranu.

  • mobile (telefon)
  • tablet
  • desktop

Nie chodzi o skalowanie, tylko o zmianę layoutu.

Meta viewport

Obowiązkowy tag <meta name="viewport" content="width=device-width, initial-scale=1.0"> aby strona skalowała się poprawnie.

Media queries

Zmiana układu na mniejszych ekranach:

/* desktop */
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

/* tablet */
@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr 1fr;
  }
}

/* mobile */
@media (max-width: 480px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Typowe granice

  • ≤ 480px → mobile
  • ≤ 768px → tablet
  • ≥ 748px → desktop

Float

Opływanie elementów za pomocą float

Podstawy

Właściwość float pozwala przesunąć element w lewo lub prawo i umożliwia tekstowi opływanie.

Przykład

.img { float: left; margin: 0 16px 16px 0; }
.clearfix::after { content: ""; display: table; clear: both; }

Tekst opływający obrazek demonstruje użycie float i konieczność czyszczenia przepływu (clearfix).

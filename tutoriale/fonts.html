Czcionki

Serif, sans-serif, font-family, font-weight i dekoracje

Co to są czcionki?

Rodzaje: szeryfowe (serif) i bezszeryfowe (sans-serif). W praktyce warto podać listę zapasową w font-family.

Przykłady

body { font-family: 'Arial', 'Helvetica', sans-serif; }
h1 { font-weight: 700; font-style: normal; text-decoration: underline; }

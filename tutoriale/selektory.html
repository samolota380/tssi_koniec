Selektory CSS

Rodzaje selektorów i ich zastosowanie w stylowaniu dokumentów HTML

Czym jest selektor?

Selektor CSS to mechanizm wskazujący elementy HTML, które mają zostać objęte stylowaniem.

Innymi słowy: selektor decyduje „co stylujemy”.

Główne typy selektorów CSS

Nazwa selektora Zapis CSS Opis
Selektor elementu (typowy) p, h1, div Wybiera wszystkie elementy danego typu HTML.
Selektor klasy .box, .menu Wybiera elementy z daną klasą. Może występować wielokrotnie.
Selektor identyfikatora (ID) #header, #main Wybiera jeden unikalny element w dokumencie.
Selektor uniwersalny * Wybiera wszystkie elementy w dokumencie.
Selektor grupowy h1, h2, p Pozwala stylować kilka elementów jednocześnie.
Selektor potomka div p Wybiera elementy znajdujące się wewnątrz innych elementów.
Selektor dziecka bezpośredniego div > p Wybiera tylko bezpośrednie dzieci elementu.
Selektor sąsiedni h1 + p Wybiera pierwszy element znajdujący się bezpośrednio po innym.
Selektor rodzeństwa ogólnego h1 ~ p Wybiera wszystkie elementy na tym samym poziomie po danym elemencie.
Selektor atrybutu input[type="text"] Wybiera elementy na podstawie atrybutów HTML.
Pseudoklasy a:hover, input:focus Reagują na stan elementu lub interakcję użytkownika.
Pseudoelementy p::first-line, p::before Stylują konkretne fragmenty elementu.

Najważniejsze w praktyce

  • Klasy są najczęściej używane w realnych projektach
  • ID powinno być rzadkie i unikalne
  • Selektory potomków są bardzo częste w layoutach
  • Pseudoklasy są kluczowe dla interakcji UI
  • Selektory atrybutów są przydatne w formularzach

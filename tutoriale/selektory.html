Selektory w CSS

Jak wybierać elementy HTML i zmieniać ich wygląd w CSS

Co to są selektory?

Selektory wskazują elementy, które mają otrzymać styl. To najważniejsza część reguły CSS: selektor { właściwość: wartość; }.

Podstawowe selektory

p { color: blue; }
.important { color: red; }
#main-title { font-size: 2rem; }
a:hover { text-decoration: underline; }

Selektory grupowe i atrybutowe

h1, h2, h3 { margin: 0; }
a[target] { color: purple; }

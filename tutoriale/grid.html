CSS Grid

Układy dwuwymiarowe z Grid

Podstawy

Grid pozwala definiować wiersze i kolumny: display:grid; grid-template-columns;

Przykład

.grid { display:grid; grid-template-columns: 1fr 2fr; gap:12px; }
.item { background:#222; padding:12px; }

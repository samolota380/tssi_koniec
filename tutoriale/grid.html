CSS Grid

Układy dwuwymiarowe z Grid

Czym jest CSS Grid?

CSS Grid to system układu dwuwymiarowego — kontroluje jednocześnie wiersze i kolumny.

  • Flexbox = 1 wymiar (wiersz lub kolumna)
  • Grid = 2 wymiary (wiersze + kolumny)

Realizuje się go poprzez display: grid;, a potem grid-template-columns i grid-template-rows na elemencie rodzica.

Grid jest przeznaczony do layoutów stron, a nie pojedynczych elementów.

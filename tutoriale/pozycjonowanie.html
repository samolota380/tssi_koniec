Pozycjonowanie elementów

position: static, relative, absolute, fixed, sticky

Jak działa position?

position określa sposób, w jaki element jest umieszczany na stronie.

  • static – domyślne, brak pozycjonowania
  • relative – przesunięcie względem siebie
  • absolute – względem najbliższego „pozycjonowanego” rodzica
  • fixed – względem okna przeglądarki
  • sticky – mieszanka relative i fixed

static vs relative

static (brak wpływu top/left)

normalny element

relative (przesunięcie)

przesunięty element o top:10px i left:20px

relative NIE usuwa elementu z układu — tylko go przesuwa.

position: absolute

absolute

rodzic ma position: relative

absolute „ucieka” z normalnego układu i liczy pozycję względem rodzica z position:relative;.

position: fixed

fixed

fixed zawsze pozostaje w tym samym miejscu ekranu, nawet podczas scrollowania. Jak widać, nie jest wtym kontenerze, tylko od samego początku "tak sobie latał" po stronie.

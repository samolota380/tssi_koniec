Pozycjonowanie elementów

position: static, relative, absolute, fixed, sticky

Omówienie

Różnice między wartościami position i jak działają top/right/bottom/left. Sticky działa względem najbliższego przodka, fixed względem viewport.

Przykłady

.relative { position: relative; }
.absolute { position: absolute; top: 10px; left: 20px; }

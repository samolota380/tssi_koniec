Animacje

transform, transition, animation i @keyframes

Transition a Animation

Początkujący często mylą transition i animation. Obie techniki służą do tworzenia ruchu, ale działają inaczej.

  • transition uruchamia się po zmianie stanu elementu (np. hover)
  • animation może działać samodzielnie bez interakcji użytkownika

Jeśli chcesz, aby przycisk płynnie zmieniał kolor po najechaniu, użyj transition. Jeśli element ma poruszać się sam przez cały czas, użyj animation.

Jak działa @keyframes?

Reguła @keyframes definiuje kolejne etapy animacji. 

@keyframes przesun {
  0% {
    transform: translateX(0);
  }

  50% {
    transform: translateX(100px);
  }

  100% {
    transform: translateX(0);
  }
}

Liczby procentowe oznaczają moment animacji:

  • 0% – początek
  • 50% – połowa czasu
  • 100% – koniec

animation-timing-function

Właściwość animation-timing-function określa tempo wykonywania animacji. Dzięki niej można sprawić, że element będzie przyspieszał, zwalniał lub poruszał się ze stałą prędkością. 

.element {
    animation: przesuniecie 2s infinite ease;
}
  • linear – stała prędkość przez cały czas
  • ease – wolny start i koniec
  • ease-in – powolny start
  • ease-out – powolne zatrzymanie
  • ease-in-out – wolny start i koniec
  • step-start – natychmiastowy skok
  • step-end – zmiana dopiero na końcu
  • steps() – animacja podzielona na kroki

animation-direction

Określa kierunek odtwarzania animacji.

  • normal – od początku do końca
  • reverse – od końca do początku
  • alternate – tam i z powrotem
  • alternate-reverse – odwrotnie tam i z powrotem

Dobre praktyki

  • Nie przesadzaj z animacjami.
  • Animacje powinny pomagać użytkownikowi, a nie rozpraszać.
  • Najwydajniejsze są animacje wykorzystujące transform i opacity.
  • Unikaj ciągłego animowania właściwości takich jak width, height, top i left.

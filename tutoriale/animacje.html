transform, transition, animation i @keyframes

Przejścia (transition)

.btn { display:inline-block; padding:10px 16px; background:#106226; color:#fff; border-radius:8px; transition: transform 180ms ease, box-shadow 180ms ease; }
.btn:hover { transform: translateY(-4px) scale(1.02); box-shadow:0 8px 20px rgba(16,98,38,0.25); }

Animacje kluczowe (@keyframes)

@keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.06); } 100% { transform: scale(1); } }
.pulse { display:inline-block; width:80px; height:80px; background:#e67e22; border-radius:12px; animation: pulse 1.6s infinite ease-in-out; }

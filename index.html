Samouczek HTML i CSS

Kompletny przewodnik po technologiach tworzenia stron internetowych. Przygotuj się do egzaminu INF.03 i uporządkuj wiedzę zdobytą podczas zajęć.

Znajdziesz tutaj najważniejsze informacje dotyczące tworzenia stron internetowych, wraz z przykładami kodu i wyjaśnieniami poszczególnych zagadnień.

Dlaczego warto poznać HTML i CSS?

HTML odpowiada za strukturę strony internetowej, natomiast CSS pozwala nadać jej odpowiedni wygląd. Są to podstawowe technologie wykorzystywane podczas tworzenia nowoczesnych witryn internetowych.
